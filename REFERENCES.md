# MediNexus One — Research and References

## Emergency service context

1. **Emergency Response Support System (ERSS), Government of India**
   - The ERSS describes 112 as a single emergency number in India for police, fire, health, and other emergency support.
   - https://112.gov.in/

2. **ERSS information page, Government of India**
   - Explains the integrated emergency response model and the relationship of existing numbers, including 108, to the unified 112 system.
   - https://112.gov.in/about

3. **Tamil Nadu government local-service directory**
   - Tamil Nadu local-government contact pages list 108 as an accident / medical-emergency helpline.
   - https://www.tnurbantree.tn.gov.in/chidambaram/important-contacts/

## Web and accessibility research

4. **MDN Web Docs: Geolocation API**

5. **MDN Web Docs: Using the Web Speech API**

6. **MDN Web Docs: SpeechSynthesis**

## Presentation disclaimer

The application uses local JSON storage for this version. Demonstration values for bed availability, patient load, doctor duty status, appointment confirmation, and indoor routes do not represent live hospital data. Emergency buttons open the device dialer; they do not dispatch an ambulance through the website.
